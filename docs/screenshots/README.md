# Screenshots

This directory holds screenshots of the dashboard and generated reports that are referenced from the
project documentation. The images are placeholders for now — capture them from a live run and drop
them in here using the suggested file names below so the documentation links resolve.

To produce material to capture, run the dashboard (`dqms dashboard`) against a representative dataset
and generate a full report (`dqms report data/customers.csv --output output/`).

## Suggested screenshots

| File name | What to capture |
| --- | --- |
| `dashboard-analyse-overview.png` | The Analyse view: score metrics row and the quality-dimensions bar chart |
| `dashboard-recommendations.png` | The Recommendations tab with prioritised advice |
| `dashboard-validation.png` | The Validation tab showing the issues table |
| `dashboard-profile.png` | The Profile tab showing per-column statistics |
| `dashboard-charts.png` | The Charts tab with an interactive histogram, box plot, or correlation heatmap |
| `dashboard-compare-drift.png` | The Compare mode showing schema and data drift |
| `report-html.png` | The rendered HTML report, including embedded charts |
| `report-pdf.png` | A page of the generated PDF report |
| `report-summary.png` | The plain-text summary output |

Use PNG format, capture at a standard desktop width, and avoid including any real or sensitive data
in the frames.
